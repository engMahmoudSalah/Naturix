# Naturix (AI Recipe Recommender)

Marketing and community site for Naturix, an app that helps households reduce food waste by turning what is already in the kitchen into recipes.

**Live:** https://naturix.mahmodsalah.workers.dev

## Highlights

- Responsive landing experience with animated sections, feature tour, vision and FAQ
- Smooth scroll animations (AOS), carousels and an interactive 3D element (react-three-fiber)
- Client-side routing with react-router

## Tech stack

React 18, Create React App, Tailwind CSS, Headless UI, React Three Fiber, AOS, react-slick.

## Hosting

Cloudflare Workers (static assets, single-page-app fallback). No paid services.

## Run locally

```bash
npm install --legacy-peer-deps
npm start
```

Production build: `npm run build`.
